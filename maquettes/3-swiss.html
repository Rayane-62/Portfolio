À propos

Profil · Alger, DZ
Portrait BMR

Développeur full stack — web, mobile, desktop

Je conçois des produits complets — du schéma de base de données au dernier pixel de l'interface.

Je travaille avec une petite équipe de développeurs sur des projets clients réels : plateformes de gestion, applications de livraison, boutiques en ligne. Chaque projet est mené de la conception à la mise en production.

Techniquement, je suis à l'aise dans l'écosystème TypeScript — React, Next.js, Angular, NestJS — avec PostgreSQL et Prisma côté données, Kotlin et React Native côté mobile.

Ce qui m'intéresse : les interfaces précises, les API propres et les produits qu'on peut maintenir à plusieurs. Je documente, je teste, et je livre dans les délais annoncés.
